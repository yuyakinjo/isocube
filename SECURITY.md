# Security Policy

## Supported versions

Security fixes are provided for the latest published version of isocube.
Please update to the latest version before checking whether an issue still occurs.
Older versions do not receive separate security backports.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/yuyakinjo/isocube/security/advisories/new).
Do not open a public issue or pull request containing vulnerability details.

Include the following information when possible:

- The affected isocube version or commit, runtime version, and operating system.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue and a minimal proof of concept.
- Any suggested mitigation or fix.

Use test data in reproductions. Do not include real credentials, personal data,
or other sensitive information.

Reports are reviewed on a best-effort basis; there is no guaranteed response or
resolution time. Please coordinate public disclosure through the private report
so a fix or mitigation can be prepared before details are published.

For non-security bugs and feature requests, please use
[GitHub Issues](https://github.com/yuyakinjo/isocube/issues).
